# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 导出任务的一致性模型

导出页面（`/exports`）由有状态模拟服务端 `src/api/exportServer.ts` 承担任务事实源，
纯领域逻辑在 `src/api/exportModel.ts`：

- **发起即固定依据**：任务创建时固化拼版版位、各轮打样结论与输出清单（FNV-1a 摘要）。
  排队中的包不会因为后续编辑而改变内容；输出清单是任务私有快照。
- **旧数据升级**：v1 任务没有依据快照，升级后一律转为「待复核」，已完成的旧分片标记为
  缺少依据、不可复用；人工「确认当前依据」后按新依据重新排队。
- **有时限执行租约**：领取 / 恢复同一任务只有一个工位成功（租约 8 秒，心跳自动续期），
  冲突返回 409；只有当前持有人能写入分片进度。页面顶部可切换工位、勾选「离线」模拟停心跳。
- **丢失续跑**：租约到期任务回到「已中断」，已完成分片保留并校验依据摘要，
  恢复时从最后完整分片的下一片继续。
- **依据一变即失效**：拼版版本或打样结论变化时自动对账，在途任务旧分片立即作废、
  状态转「依据失效」，页面横幅与导航徽标列出受影响任务；「用新依据重试」整体切换依据并清空旧分片。
  已完成任务不删除原交付件，而是标记为「被新依据取代」，可选择重新生成。
